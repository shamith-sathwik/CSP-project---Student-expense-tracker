## Project Description

The **Student Expense Tracker** is a web-based application designed to help students manage and monitor their daily and monthly expenses. Users can create an account, log in, set a monthly budget, add expenses under different categories, view their spending history, and analyze their expenses using graphical charts.

The application also includes an **Administrator Dashboard** that allows the administrator to view registered users and the number of expenses logged by each user.

## Features

- User Registration and Login
- Admin Login and Dashboard
- Add and Delete Expenses
- Multiple Expense Categories
- Monthly Budget Management
- Total Spending and Remaining Balance Calculation
- Monthly Expense Filtering
- Expense History
- Doughnut Chart for Expense Distribution
- Bar Chart for Category-wise Spending
- Download Monthly Expense Report as a CSV File
- User Logout

## Technologies Used

## How to Use the Application

1. Open the application in your web browser.
2. Create a new account using the **Register** page.
3. Log in using your username and password.
4. Set your monthly budget.
5. Add expenses by selecting a category, entering the amount, date, and an optional note.
6. View your total spending and remaining budget.
7. Use the charts to analyze your spending by category.
8. View or delete expenses from the expense history.
9. Download the monthly expense report as a CSV file.
10. Log out after completing your work.
